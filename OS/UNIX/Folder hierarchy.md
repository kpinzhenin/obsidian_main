детальную информацию о назначении и расположении папок в установленной системе можно получить командой:
```bash
man hier
```
но в общем случае основные назначения следующие:

Директории для хранения бинарных файлов:
- /bin -  содержит бинарные файлы, которые могут использоваться всеми пользователями.
- /sbin - содержит бинарные файлы, предназначенные для настройки операционной системы. `ipconfig`, `fdisk` для примера.
- /lib , /lib64- содержит разделяемые ресурсы, которые в том числе используют исполняемые из `/bin`.
- /opt - сокращение от *option*. Служит для хранения *вспомогательного* программного обеспечения. Которое устанавливается не из официального репозитория дистрибутива.

Директории хранения файлов конфигурации:
- /boot - содержит все файлы, необходимые для загрузки компьютера.
- /etc - расшифровывается, как ( *Editable Text Configuration* ). Содержит все специфичные для машины конфигурационные файлы

Директории для хранения данных:
- /home - служит для хранения персональных данных пользователя. Помимо выделения каждому пользователю (или каждому проек­ту или группе) места для хранения персо-нальных данных в рамках домашней директории, в рамках этой же директории выде-ляется ме­сто для хранения данных профиля пользователя.
- /root - является стандартной директорией для хранения персональных данных и данных профиля пользователя root.
- /srv - предполагается, что здесь будут храниться  данные, которые *обрабатываются системой*
- /media - точка монтирования внешних устройств ( USB )
- /mnt - должна быть пустой и использоваться исклю­чительно для создания временных точек монтирования файловых си­стем.
- /tmp - для хранения временных данных при необходимости. Ибо она периодически очищается.

Директории в оперативной памяти:
- /dev - содержит описание установленных в системе устройств.
	- /dev/null - черная дыра для удаления.
	- /dev/tty - терминал соединенный с системой.
	- /dev/pts -  терминал графического окружения рабочего стола.
- /proc - содержание является представлением ядра ОС. утверждается, что туда монтируется специальная файловая система  `procfs`
	- /proc/cpuinfo - содержит информацию о процессоре
	- /proc/interrupts - содержит информацию о запросах прерываний
- /sys - содержит файлы с информацией об используемом аппаратном обеспечении. Исполльзуется система `sysfs` для реализации механизма горячего подключения усттройств по шине `USB` или IEEE 1394( FireWire)

Директория системных ресурсов:
 - /usr - расшифровывается как ( *Unix System Resources* ). должна содержать разделяемые данные приложений, доступные только для чтения.
	 - /usr/bin - содержит множество реализаций команд.
	 - /usr/include - содержит общедоступные заголовоч­ные файлы для языка программирования C.
	 - /usr/lib - содержит разделяемые библиотеки, кото­ рые не используются непосредственно  пользователями или сценариями.
	 - /usr/local - может использоваться для локальной установки программного обеспечения.
	 - /usr/share - содержит независимые от архитектуры данные.Обычно данная директория содержит поддиректорию /usr/share/man, предназначенную для хранения файлов страниц руководств.
	 - /usr/src - является рекомендуемой директорией для хранения файлов исходного кода ядра ОС.

Директория для изменяемых данных:
 - /var - содержит файлы заранее не известного размера, такие как файлы журналов, файлы кэша и файлы очереди печати.
	 - /var/log выполняет функции центрального хранилища всех файлов журналов.
	 - /var/log/messages - По умолчанию данный файл должен содержать информацию о событиях, которые происходят в рамках системы.
	 - /var/cache - может содержать кэшированные данные некоторых приложений.
	 - /var/spool обычно содержит поддиректории для хранения файлов с сообщениями электронной почты и данными за­ дач cron.
	 - /var/lib - содержит файлы с данными состояния приложений

В скрипте можно использовать любые команды, начинающиеся с `:`, т.е. любые которые можно использовать в командной строке.
`vimrc` тоже скрипт файл.
Для открытия файла `vimrc` файла используется команда 
```vim
:edit $MYVIMRC
```
в UNIX системах файл находится в `~/.vimrc`
строка комментария начинается символом `"`

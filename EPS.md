EFI System Partition в которые должен быть установлен загрузчик ( `bootloader`). Не обязательно создавать раздел как первый раздел, он может быть создан где угодно, но следует иметь FAT32/16 файловую систему. 
Рекомендованный размер 256Мб.
EFI System Partition
	- EFI
		- <OS_vendor_name>
			- <boot_loader_files>
После создания загрузчик должен быть установлен в:
`/EFI/<os_vendor_name>/`

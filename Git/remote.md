```bash
git remote -v #показать удаленные репозитории
```


``` bash
git remote add <origin> <URL> # добавить удаленный репозиторий
```

Обновить состояние удаленного репозитория:
```bash
git remote update
```

Посмотреть ветки удаленного репозитория:
```bash
git branch -r
```


```bash
git remote show <origin> # Просмотр удаленного репозитория:
``` 

```bash
git remote rm <origin name> # Удаление remote репозитория
``` 

```bash
git remote prune <origin name> # обновление кэша remote репозитория
```

Посмотреть какие созданы.
```bash
git branch
```
Создание новой ветки, только создание. Переход на новую ветку другой командой осуществляется.
```bash
git branch <branch_name>
```
Переход к новой ветке
```bash
git checkout <branch_name>
```
Удаление ветки
```bash
git branch -d <branch_name>
```
Удаление ветки в remote репозитории производится командой [[push]]
Посмотреть ветки remote репозитория
```bash
git branch -r
```
Посмотреть вообще все ветки и remote и local
```bash
git branch -a
```

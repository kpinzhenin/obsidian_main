Позволяет сохранить изменения в стеке не коммитя их. Простой пример позволяет сохранить `unstaged` и `untracked` файлы, чтобы вернуться к ним позже
```bash
git stash push -m "<comment>"
```
посмотреть состояние стека:
```bash
git stash list # выведет все строки с комментарями
```
достать  и удалить из стека:
```bash
git stash pop # извлекает именно последнюю версию
git stash stash@{0} # извлекает и удаляет конкретный из стэка
```
чтобы достать и не удалять из стека:
```bash
git stash apply
git stash apply stash@{0}
```

Удаляет файл из рабочего каталога и индекса.
```bash
git rm <file_name> - удаляет файл из рабочего каталога и индекса
```
Удалить файлы из репозитория( прекратить отслеживать ), при этом оставить в рабочем каталоге( `worked directory`):
```bash
git rm --cached <file_name>
git commit
```

Эта команда походу больше не работает - смотри [[restore]]
```bash
git rm --staged <file_name> # удалить файл из индекса 
```

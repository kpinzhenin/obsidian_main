BIOS - basic input output system. Прошивка материнской платы, разработана в 1982 году для IBM PC-5150.
имеет поддержку только 16-битных инструкций. Даже если сам CPU поддерживает 32/64 битные инструкции. По этой причине у CPU есть несколько режимов работы ( real, protected и long )
 - real mode - CPU ограничен 16-битными инструкциями.
 - protected mode - уже имеет 32-битные инструкции.
 - long mode - 64-битные инструкции, в нем видимо и загружается ядро системы.

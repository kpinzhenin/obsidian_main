Bash расшифровывается, как _Bourne again shell_
Исторически выделяется несколько оболочек:
 - `sh` - оригинальная командная оболочка Стивена Борна
 - `csh` - командная оболочка Билла Джоя с поддержкой сценариев, синтаксис которых основан на синтаксисе языка программирования C
 - `ksh` - командная оболочка Дэвида Корна

 Аргументы командной строке передаются через пробел. Строки в одинарных или двойных кавычках воспринимаются как один аргумент. Разница в работе одинарных и двойных кавычек обнаруживается при использовании с переменными среды или командной оболочки ( `$<var_name>`), в двойных кавычках переменная передает свое значение, однако в одинарных передается имя вместе в `$`
 Для поочередного вывода команд используется `;`
 ```bash
echo WOE; echo second
WOE
second
 ```
 При указании `&` оболочка не будет дожиться исполнения команды - команда будет исполняться в фоне.
 
 Код возврата предыдущей команды можно посмотреть в параметре `$?`
```bash
touch file1
echo $?
```

При указании `&&` логическое "И". т.е. вторая команда будет исполняться если первая завершилась успешно ( причем именно вернула 0, а не 1 ( как в случае ошибки ) )

Противоположное значение у оператора `||` вторая команда будет выполнена, только если первая не выполнялась.

знак `#` предшествует комментариям ( по большей части используется в написании скриптов )

Звездочка `*` интерпретируется командной оболочкой как символ для генерации списка имен файлов, причем сам символ звездочки может преобразовываться в любую комбинацию символов (или даже в строку без символов).

Утилита для определения типа файла. Как я понял на основе сигнатуры файла определеляется его тип.
В книге описывается как "магические последоватльности байт", файл со списком можно найт по адресу `/usr/share/file/magic`
```bash
file -s # для открытия системных файлов 
```
в любом случае командой 
```bash
man file
```

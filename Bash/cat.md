Утилита копирует данные из `стандартного потока ввода` в `стандартный поток вывода`.
Можно создать файл с использованием `cat`:
```bash
cat >some_file.txt
erewrwg
# ввод будет продолжаться до нажатия сочетания Ctrl+D
# что соответсвует последовательности EOF ( End Of 
# File)
cat >hot.txt <<end_file_sign #тоже конец файла, но уже в виде строки
```

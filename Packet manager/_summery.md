Менеджер пакетов - программа которая управляет установкой, удалением и отслеживает зависимости между компонентами в ОС. Как выяснилось есть несколько уровней менеджеров пакетов .... 
### Системный 
Управляют ядром, библиотеками и системными службами. 
 - `dnf` в Fedora ( работает с `rpm` пакетами )
 - `apt` в Ubuntu
 - `pacman` в Arch
### Универсальные ( для графических приложений )
Не зависят от конкретно установленного дистрибутива. Предназначен для изоляции устанавливаемых приложений от системы. 
 - Flatpak - является приоритетным способом установки приложений в Fedora
 - Snap
 - AppImage - программа поставляется в виде одного исполняемого файла.
### Для языков программирования
 - `pip` - Python
 - `npm` - JavaScript/Node.js
 - `Cargo` - Rust
